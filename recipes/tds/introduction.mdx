These recipes show how to use Sandbox APIs for Tax Deducted at Source (TDS) compliance. Follow the code samples and API sequences to prepare returns, file them, and generate salary and non-salary TDS certificates.

<Tip>
Start with the [TDS API overview](/api-reference/tds/overview) to choose the APIs for your workflow.
</Tip>
