# Income Tax (IT) Context

## Overview

Income Tax is a form of direct tax levied on the income generated by individuals, businesses, companies, and other entities. Managed by the Indian Income Tax Department, it is a fundamental revenue source for the Government of India.

Income is classified into five different sources:
1. **Income from Salary** - Compensation received from employment
2. **Business & Professional Income** - Income from business operations or professional services
3. **Capital Gains** - Income from sale of assets (short-term or long-term)
4. **Income from House Property** - Rental income from property ownership
5. **Income from Other Sources** - Interest, dividends, and other miscellaneous income

Tax liability is calculated based on the applicable tax regime:
- **Old Tax Regime** - Traditional slab-based taxation with deductions and exemptions
- **New Tax Regime** - Simplified tax rates with fewer deductions (effective FY 2020-21)

### Filing Requirements
- **Individuals/HUF**: Mandatory to file ITR if gross income exceeds INR 2.5 lakhs in a financial year
- **Companies/Firms**: Mandatory to file ITR regardless of income level
- **Partnerships**: Required to file even if income is below threshold
- **Capital Gains**: Filing required even if capital gains are the only income source

### Key Challenges
- Tax laws and rate changes with each budget session
- Complex tax calculations based on asset classes (securities, crypto, forex)
- Multiple filing requirements (ITR, ITR Annexures, schedules)
- Document extraction and verification (Form 16, Form 26AS, bank statements)
- Reconciliation between income sources and capital assets
- Compliance deadlines (ITR filing, advance tax installments)

## Income Tax APIs - Core Modules

### Calculator APIs
Compute tax liability and advance tax obligations across different income scenarios and asset classes.

**Capabilities:**
- Calculate income tax liability under old and new tax regimes
- Compute advance tax (quarterly installments)
- Calculate tax impact for specific transactions (securities trading, crypto, forex)
- Support flexible input formats (tradewise, scripwise, tradebook, portfolio data)
- Apply applicable deductions (Section 80C, 80D, etc. under old regime)
- Handle loss adjustments and loss carry-forward scenarios

**Common Calculations:**
- **Income Tax Liability**: Based on total taxable income and applicable slab rates
- **Advance Tax**: Quarterly installments (15% + 15% + 30% + 40%)
- **Tax on Securities**: Domestic stocks, mutual funds, derivatives with holding period classification
- **Tax on Crypto**: Short-term capital gains, long-term gains, transfer transactions
- **Tax on Forex/Foreign Assets**: FDI, NRE accounts, foreign property

### Report APIs
Generate compliance-ready reporting outputs for tax filing, audits, and stakeholder communication.

**Capabilities:**
- **ITR Preparation**: Generate JSON-formatted ITR data for uploading to Income Tax portal (portal.incometax.gov.in)
- **Tax P&L Reports**: Comprehensive profit & loss reporting across asset classes
- **Reconciliation Reports**: Match calculated tax with actual ledger entries
- **Audit Reports**: Detailed schedules and supporting documentation for audits
- **Asset Summary**: Consolidated view of all income sources and transactions

**Output Formats:**
- JSON (for ITR upload to IT portal)
- PDF (for audit and compliance reports)
- Excel/CSV (for ledger integration and analysis)

**Common Reports:**
- **ITR Report**: Individual tax return formatted for government filing
- **Tax P&L - Securities**: Profit/loss breakdown for domestic securities trading
- **Tax P&L - Crypto**: Gains/losses from cryptocurrency transactions
- **Tax P&L - Forex/NRE**: Foreign currency and international asset transactions
- **Deduction Summary**: Section 80C, 80D, and other applicable deductions
- **Loss Carryforward**: Losses available for future year adjustment

### OCR APIs
Automated document extraction for tax processing and verification.

**Capabilities:**
- Extract structured data from PDF forms and documents
- Classify and parse tax-relevant fields automatically
- Support multiple document types and form variations
- Return extraction results in structured JSON format
- Handle handwritten and printed documents

**Supported Documents:**
- **Form 16**: Certificate of tax deducted at source (Deductor section)
  - Employer details, salary breakdown, tax deduction, declarations
  - Returns: Employee name, PAN, gross salary, tax details, investment declarations
  
- **Form 26AS**: Tax collected at source statement (Individual section)
  - All TDS transactions during financial year
  - Returns: Creditable tax amounts, transaction dates, deductor details
  
- **Form 12BA**: Certificate for remittance of tax on income from other sources
- **Bank Statements**: Extract transaction data for verification
- **Salary Slips**: Parse salary components and taxes deducted

## API Patterns and Standards

### Authentication
- Bearer token authentication
- API key format: `key_test_...` (test) or `key_live_...` (production)
- JWT-based access tokens (24-hour validity)
- See sandbox_context.md for detailed authentication details

### Request Structure
- Method-specific patterns: GET (retrieve), POST (create/submit), PUT (update)
- JSON request bodies with hierarchical structure
- Flexible input formats to support various data sources
- Batch processing support for bulk operations

### Response Structure
```json
{
  "code": 200,
  "data": { /* API-specific response */ },
  "timestamp": 1750687659809,
  "transaction_id": "unique-id"
}
```

### Async Processing Pattern
Many Income Tax calculations and report generation are async jobs:

1. **Submit Request**: POST to initiate job → Get `job_id`
2. **Poll Status**: GET job status endpoint with `job_id` → Returns processing status
3. **Fetch Results**: GET results endpoint once status is complete → Returns calculation or report

**Job Status Values:**
- `PENDING`: Job queued, processing not yet started
- `IN_PROGRESS`: Actively processing
- `COMPLETED`: Successfully completed, results available
- `FAILED`: Processing failed, check error details
- `CANCELLED`: Job was cancelled

**Benefits:**
- Handle large calculations without timeout
- Support bulk processing and reporting
- Enable progress tracking for long-running operations

## Terminology

### Tax Concepts
- **ITR**: Income Tax Return - statutory filing with income tax department
- **FY/AY**: Financial Year (April-March) / Assessment Year (tax year being assessed)
- **TDS**: Tax Deducted at Source - tax withheld during payments
- **TCS**: Tax Collected at Source - tax collected on sale transactions
- **Advance Tax**: Quarterly tax installments on estimated income
- **Deduction**: Allowed expenditure reducing taxable income (Section 80C, etc.)
- **Exemption**: Income exempt from taxation (HRA, LTA, etc.)
- **Loss Carry-forward**: Business losses that can be adjusted in future years

### Asset Classifications
- **Securities**: Listed stocks, mutual funds, derivatives (short-term if <1yr, long-term if ≥1yr)
- **Crypto**: Digital assets (classified as capital assets for taxation, holding period matters)
- **Forex/NRE**: Foreign currency accounts and international assets
- **Derivatives**: Futures, options, covered calls (traded on recognized exchanges)
- **P2P/Alternative Assets**: Peer-to-peer lending, fractional ownership platforms

### Document Types
- **Form 16**: TDS Certificate from employers
- **Form 26AS**: TDS Statement from IT Department
- **Form 12BA**: TDS Certificate for non-salary income
- **Certificates**: Investment certificates (life insurance, NSC, etc. for Section 80C)

### Statutory References
- **Section 80C**: Deduction up to INR 1.5 lakhs for specified investments
- **Section 80D**: Deduction for health insurance premiums
- **Section 80E**: Deduction for education loan interest
- **Section 80G**: Deduction for charitable donations
- **Section 115AD/115B**: Special provisions for long-term capital gains
