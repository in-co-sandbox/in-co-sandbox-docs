## Tax P&L Summary Sheet

### Asset Wise Summary Table

| Param | Type | Description |
| :--- | :--- | :--- |
| asset\_class | `string` | Asset class, possible values are `stock`, `mutual_fund`, `etf`, `dr` |
| asset\_type | `string` | Asset category, e.g., `equity`, `debt` |
| income\_head | `string` | The income head of **ITR** under which the income of a specific income is to be reported |
| income\_sub\_head | `string` | The income subhead of **ITR** under which the income of a specific income is to be reported |
| section | `string` | Applicable section of the Income Tax Act |
| holding\_period | `string` | The holding period of the asset, possible values are `long_term` or `short_term` |
| turnover\_inr | `number` | Turnover of the transactions (in **INR**) |
| buy\_value\_inr | `number` | Sum of buy value for all trades of the asset (in INR) |
| cost\_of\_acquisition | `number` | Sum of the cost of acquisition for all trades (in INR) |
| sell\_value\_inr | `number` | Sum of sell value for all trades (in INR) |
| realized\_pnl\_inr | `number` | Total realized profit or loss for the asset class (in INR) |
| unrealized\_pnl\_inr | `number` | Total unrealized profit or loss for the asset class (in INR) |
| expenses\_inr | `number` | Sum of all expenses incurred for the transactions (in INR) |
| stt\_inr | `number` | **Securities Transaction Tax** paid (in INR) |
| cess\_inr | `number` | Education Cess paid (in INR) |
| tax\_payable\_inr | `number` | Tax payable for the asset class (in INR) |
| reporting\_head | `string` | Reporting head under which the income of a specific trade is to be reported |
| tax\_rate | `string` | The applicable tax rate for the trade |

| total\_expenses\_inr | `number` | Total expenses incurred (in INR) |

| total\_tax\_payable\_inr | `number` | Total tax payable (in INR) |
| other\_income\_inr | `number` | Total other income (e.g., dividends, interest) (in INR) |
