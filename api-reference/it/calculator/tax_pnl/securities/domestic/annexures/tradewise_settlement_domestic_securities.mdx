---
title: "Tradewise Settlements | Domestic Securities"
---

Reference sheet for preparing domestic securities tradewise settlements across asset classes. Each section outlines the expected schema for trades, last traded prices, dividends, and other expenses. Use these tables to validate or map broker exports before uploading to Sandbox Income Tax Annexures.

## Stock Sheet

### Stock Tradewise Table
| Param                        | Type      | Required | Description                                               |
| :--------------------------- | :-------- | :------- | :-------------------------------------------------------- |
| isin                         | `string`  | No       | International Security Identification Number              |
| symbol                       | `string`  | Yes      | Symbol or description of equity share                     |
| is_listed                    | `boolean` | Yes      | Indicates if the equity stock is listed on public markets |
| is_stt_paid                  | `boolean` | Yes      | Whether STT was paid on this trade                        |
| quantity                     | `number`  | Yes      | Trading quantity                                          |
| buy_trade_id                 | `string`  | Yes      | Buy Trade ID                                              |
| buy_date                     | `number`  | Yes      | Epoch timestamp of purchase                               |
| buy_price                    | `number`  | Yes      | Buy price                                                 |
| sell_trade_id                | `string`  | Yes      | Sell Trade ID                                             |
| sell_date                    | `number`  | Yes      | Epoch timestamp of sale                                   |
| sell_price                   | `number`  | Yes      | Sell price                                                |
| fmv                          | `number`  | No       | Fair market value as on 31/01/2018                        |
| brokerage                    | `number`  | No       | Brokerage expense                                         |
| clearing_charges             | `number`  | No       | Clearing house charges                                    |
| exchange_transaction_charges | `number`  | No       | Exchange transaction charges                              |
| sebi_turnover_fees           | `number`  | No       | SEBI turnover fee                                         |
| stt                          | `number`  | No       | Securities Transaction Tax                                |
| stamp_duty                   | `number`  | No       | Stamp duty paid                                           |
| sgst                         | `number`  | No       | State GST                                                 |
| cgst                         | `number`  | No       | Central GST                                               |
| igst                         | `number`  | No       | Integrated GST                                            |
| other_transfer_expenses      | `number`  | No       | Other transfer-related expenses                           |
| nature_of_settlement         | `string`  | No       | See Annexure 2: Nature of Settlement                      |
| product_type                 | `string`  | Yes      | `delivery` or `intraday`                                  |
