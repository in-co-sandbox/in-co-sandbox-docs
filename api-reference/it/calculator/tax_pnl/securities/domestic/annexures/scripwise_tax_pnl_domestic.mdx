## Tax Pnl Summary Sheet

### Assetwise Summary Table

| Param | Type | Required | Description |
| :---- | :---- | :---- | :---- |
| asset_class | `string` | Yes | Asset class of the securities, possible values  <br/>`equity`, `debt`, `other` |
| asset_type | `string` | Yes | Asset type of the instrument, possible values  <br/>`stock`, `mutual_fund`, `etf`,`future`,`option`,`bond`,`debenture` |
| income_head | `string` | Yes | Income head under which income from a particular asset type is taxed  <br/>Possible values, `capital_gains`,`business_and_profession`,and `other` |
| income_sub_head | `string` | Yes | Income sub-head of that income head, possible values  <br/>`securities`, `other_capital_gains`,`speculative`,`non-speculative` |
| tax_rate | `string` | Yes | The rate at which a particular income is to be taxed as per Income Tax Act. |
| section | `string` | No | The section under which it will be taxed |
| holding_period | `string` | Yes | Holding period, possible values  <br/>`intraday`, `long_term`,  `short_term` |
| turnover | `number` | Yes | Turnover or revenue from a particular asset type |
| buy_value | `number` | Yes | Total purchase value  |
| cost_of_acquisition | `number` | Yes | Total purchase value after considering its FMV as on 31.01.2018 |
| sell_value | `number` | Yes | Total sale value |
| realized_pnl | `number` | Yes | The realized profit or loss on the asset without considering transfer expenses |
| transfer_expense | `number` | No | Any expense relating to the transfer of an asset. |
| net_realized_pnl | `number` | Yes | The realized profit or loss on the asset after considering transfer expenses |
| taxable_pnl | `number` | Yes | The profit after losses adjustment on which taxes are calculated. |
