# Income Tax OCR APIs

The OCR (Optical Character Recognition) APIs automate the extraction and classification of data from tax documents. These APIs parse PDFs and images to extract structured information for tax workflows.

## How It Works

1. **Upload Document**: Submit PDF or image file
2. **Processing**: System extracts and classifies data
3. **Get Results**: Receive structured JSON with confidence scores

## Document Processing

Each document type has its own specialized endpoint optimized for extraction:

**Form 16 Endpoint**: Extracts salary details, TDS information, and investment declarations from TDS certificates issued by employers.

**Form 26AS Endpoint**: Extracts creditable TDS amounts, deductor details, and tax payment information from the annual TDS statement.
