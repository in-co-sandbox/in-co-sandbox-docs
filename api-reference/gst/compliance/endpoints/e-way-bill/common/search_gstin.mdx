## NIC validations

<Accordion title="View NIC validations">

1. An attribute "status" has been Added('ACT' or 'CNL' or 'INA' or 'PRO')
2. An attribute "blkStatus" has been Added\
   i) 'U' or ' ' for Unblocked\
   ii) 'B' for blocked

</Accordion>
