## Who can update the e-way bill transporter?

<Info>
Only the current transporter can change an existing transporter assignment. The new transporter ID must be a valid GSTIN or TRANSIN.
</Info>

The e-way bill must be active and within its validity period.

Source: [NIC API validations](https://docs.ewaybillgst.gov.in/apidocs/version1.03/update-transporter.html).
