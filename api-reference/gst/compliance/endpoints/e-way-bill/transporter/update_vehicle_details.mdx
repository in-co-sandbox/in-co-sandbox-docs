## Who can update Part-B vehicle details?

<Info>
The requester must be the assigned transporter under NIC's API validations.
</Info>

The e-way bill must be active and within its validity period.

Source: [NIC API validations](https://docs.ewaybillgst.gov.in/apidocs/version1.03/vehicle-number-update.html).
