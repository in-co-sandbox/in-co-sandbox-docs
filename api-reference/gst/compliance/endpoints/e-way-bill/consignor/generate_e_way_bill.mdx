## Who can generate an e-way bill?

<Info>
A consignor, consignee, or transporter can generate an e-way bill, subject to NIC's generation requirements. The taxpayer or transporter who generates the e-way bill is its generator.
</Info>

For transactions that NIC requires to use the e-invoice system, the e-way bill must be generated through the e-invoice APIs, either while generating the Invoice Reference Number (IRN) or by referencing an existing IRN.

Source: [NIC API validations](https://docs.ewaybillgst.gov.in/apidocs/version1.03/generate-eway-bill.html).
