## Who can retrieve an e-way bill by document details?

<Info>
NIC treats the requester GSTIN as the generator GSTIN for this lookup. A consignor or consignee can retrieve an e-way bill using this API only if they generated it.
</Info>

Only active e-way bills are returned.

Source: [NIC API validations](https://docs.ewaybillgst.gov.in/apidocs/version1.03/get-eway-bill-by-docNo.html).
