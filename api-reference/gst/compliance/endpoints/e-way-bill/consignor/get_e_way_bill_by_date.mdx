## NIC validations

The `rejected` query parameter selects the NIC API that Sandbox calls. Each NIC API applies its own validations.

<Accordion title="View NIC validations">

#### When `rejected` is `false`

1. Only E-way bill generator can access this API.
2. Only active E-way bills will be considered in this API.

#### When `rejected` is `true`

1. Only E-way bill generator can access this API.

</Accordion>
