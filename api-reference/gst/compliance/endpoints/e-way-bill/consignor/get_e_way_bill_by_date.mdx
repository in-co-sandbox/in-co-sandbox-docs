## Which e-way bills can you retrieve?

<Info>
This lookup returns only e-way bills generated by your GSTIN. Being named in an e-way bill is not sufficient.
</Info>

With `rejected=false`, the lookup returns active e-way bills generated on the specified date. With `rejected=true`, the lookup returns e-way bills you generated that other parties rejected, for the date passed to NIC. NIC does not specify whether that date is the generation date or the rejection date. The rejected e-way bills lookup does not reject an e-way bill.

Source: [NIC API validations](https://docs.ewaybillgst.gov.in/apidocs/version1.03/get-eway-bills-by-date.html) and [NIC rejected e-way bills lookup](https://docs.ewaybillgst.gov.in/apidocs/version1.03/get-eway-bills-rej-by-others.html).
