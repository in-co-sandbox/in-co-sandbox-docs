## Who can regenerate a consolidated e-way bill?

<Info>
A consignor or consignee can use this API if they generated the consolidated e-way bill. NIC also permits the current transporter to regenerate the consolidated e-way bill.
</Info>

Only active e-way bills within their validity period are considered during regeneration.

Source: [NIC API validations](https://docs.ewaybillgst.gov.in/apidocs/version1.03/regenerate-trip-sheet.html).
