## Who can extend e-way bill validity?

<Info>
Under NIC's API validations, a consignor or consignee can use this API if they generated the e-way bill and no transporter is assigned. Once a transporter is assigned, only the current transporter can extend e-way bill validity.
</Info>

An extension can be requested within eight hours before or after expiry. The request must include the extension reason, current location, and remaining distance. NIC does not permit extension beyond 360 days from e-way bill generation.

Source: [NIC API validations](https://docs.ewaybillgst.gov.in/apidocs/version1.03/extend-validity.html).
