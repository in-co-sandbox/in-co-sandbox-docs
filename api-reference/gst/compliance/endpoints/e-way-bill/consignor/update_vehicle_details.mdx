## Who can update Part-B vehicle details?

<Info>
Under NIC's API validations, a consignor or consignee can use this API if they generated the e-way bill and no transporter is assigned. Once a transporter is assigned, the assigned transporter must update Part-B.
</Info>

The e-way bill must be active and within its validity period.

Source: [NIC API validations](https://docs.ewaybillgst.gov.in/apidocs/version1.03/vehicle-number-update.html).
