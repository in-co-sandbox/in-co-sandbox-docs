## Which e-way bills can you retrieve?

<Info>
A consignor or consignee can use this lookup to review e-way bills generated by other parties against their GSTIN. This lookup does not return e-way bills you generated.
</Info>

The generation date must be one of the previous three days. The current date is not supported.

Source: [NIC API validations](https://docs.ewaybillgst.gov.in/apidocs/version1.03/get-other-party-eway-bill.html).
