## Who can reject an e-way bill?

<Info>
If the supplier generated the e-way bill, the recipient can reject it. If the recipient generated the e-way bill, the supplier can reject it. If a transporter generated the e-way bill, either the supplier or recipient can reject it.
</Info>

Source: [NIC API validations](https://docs.ewaybillgst.gov.in/apidocs/version1.03/reject-eway-bill.html) and [NIC e-way bill FAQ](https://docs.ewaybillgst.gov.in/html/faq.html).
