---
title: 'List Purchase E-Invoices Job'
description: "Submit a job to get list of purchase e-Invoice details for the specified return period."
openapi: '/api-reference/gst/compliance/openapi.json POST /gst/compliance/tax-payer/e-invoices/{year}/{month}/purchases'
---
<Info>
  **Authentication:** This endpoint does not use standard Sandbox JWT authentication. Pass the GST taxpayer `access_token` in the `Authorization` header. Refer to the [**Generate Taxpayer Session**](/recipes/gst/authentication/generate_tax_payer_session) recipe for steps to generate this token.
</Info>

<Info>
Only e-Invoices within the last 6 months can be fetched.
</Info>
