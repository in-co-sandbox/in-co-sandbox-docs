# GSTR-9 API

GSTR-9 is the **GST annual return** filed once per financial year to report consolidated purchases, sales, input tax credit (ITC), and tax paid for a GSTIN. **File** GSTR-9 programmatically by fetching GSTN-prepared annual summaries, reviewing Section 8A ITC, saving the draft, proceeding to filing, generating EVC OTP, submitting the return, and tracking filing status on the GST portal.

## How it works

<Steps>
  <Step title="Initiate taxpayer session">
    Authenticate and start a taxpayer session by following the [Generate Taxpayer Session](/recipes/gst/authentication/generate_tax_payer_session) recipe.
  </Step>
  <Step title="Fetch current GSTR-9 draft">
    Pull the latest draft state for the target financial year using [Get GSTR-9 details](/api-reference/gst/compliance/endpoints/taxpayer/gstr-9/gstr_9_details).
  </Step>
  <Step title="Fetch auto-calculated annual totals">
    Retrieve GSTN auto-calculated values using [Get auto-calculated details](/api-reference/gst/compliance/endpoints/taxpayer/gstr-9/auto_calculated_details).
  </Step>
  <Step title="Fetch Section 8A details">
    Review portal-populated ITC figures using [Get Section 8A details](/api-reference/gst/compliance/endpoints/taxpayer/gstr-9/section_8a_details).
  </Step>
  <Step title="Prepare HSN mapping (if needed)">
    Use [Get HSN](/api-reference/gst/compliance/endpoints/taxpayer/gstr-1/documents/get_hsn) to build and validate HSN/SAC-level summaries where required for annual reporting.
  </Step>
  <Step title="Save draft">
    Submit prepared values using [Save GSTR-9](/api-reference/gst/compliance/endpoints/taxpayer/gstr-9/save) to store the annual return as a draft.
  </Step>
  <Step title="Proceed to filing">
    Trigger GSTN validations using [Proceed GSTR-9](/api-reference/gst/compliance/endpoints/taxpayer/gstr-9/proceed).
  </Step>
  <Step title="Generate EVC OTP, file, and track status">
    Request [Generate EVC OTP](/api-reference/gst/compliance/endpoints/taxpayer/authentication/generate_evc_otp), submit [File GSTR-9](/api-reference/gst/compliance/endpoints/taxpayer/gstr-9/file), then poll [Get GST return status](/api-reference/gst/compliance/endpoints/taxpayer/common/gst_return_status).
  </Step>
</Steps>

## Common use cases

Use the GSTR-9 API when you need to:

- **ERP annual GST filing**: Consolidate FY sales and purchases in your ERP, then use GSTR-9 APIs to draft and file the annual return for each GSTIN.
- **CA or tax team bulk filing**: File GSTR-9 for dozens or hundreds of GSTINs with standardized draft-save-proceed-file tracking and audit logs.
- **Reconciliation-first workflow**: Compare auto-calculated values and Section 8A ITC against internal books to identify variances before filing.
- **Return status monitoring**: Build a "Filing Timeline" UI that polls GST return status and alerts users when GSTR-9 is filed or needs action.
- **HSN summary preparation**: Validate HSN codes and build HSN-level summaries using HSN utilities to reduce classification errors.

## FAQs

<AccordionGroup>
  <Accordion title="What is GSTR-9 and who needs to file it?">
    GSTR-9 is the GST annual return that consolidates purchases, sales, input tax credit, and tax paid for a financial year. Regular taxpayers registered under GST must file GSTR-9 annually, except those exempted by government notification. Some taxpayer categories may have different annual return requirements or may be exempt as notified by the government. Filing is mandatory once all periodic returns for the FY are completed; see [File GSTR-9](/recipes/gst/gstr-9/file_gstr_9) for the API workflow.
  </Accordion>
  <Accordion title="How does the GSTR-9 API filing flow work end-to-end?">
    The GSTR-9 API filing flow starts with initiating a taxpayer session for the GSTIN. Next, fetch the current draft and auto-calculated annual totals from GSTN. Review Section 8A ITC details and prepare HSN mappings if needed. Save the draft using the [Save GSTR-9](/api-reference/gst/compliance/endpoints/taxpayer/gstr-9/save) endpoint, then proceed to trigger validations. Generate an EVC OTP via the [Generate EVC OTP](/api-reference/gst/compliance/endpoints/taxpayer/authentication/generate_evc_otp) endpoint, file the return, and poll [GST return status](/api-reference/gst/compliance/endpoints/taxpayer/common/gst_return_status) until confirmation.
  </Accordion>
  <Accordion title="What are auto-calculated details and how should I use them?">
    Auto-calculated details are GSTN-prepared annual summaries based on periodic returns filed during the financial year. The GSTR-9 API retrieves these values as a reconciliation baseline - compare them against your internal books to identify discrepancies before populating the draft. Access them via the [Get auto-calculated details](/api-reference/gst/compliance/endpoints/taxpayer/gstr-9/auto_calculated_details) endpoint.
  </Accordion>
  <Accordion title="What is Section 8A and why does it matter for ITC in GSTR-9?">
    Section 8A contains ITC figures auto-populated by the GST portal from supplier returns for the financial year. GSTR-9 reporting depends on these values for annual ITC reconciliation. Review Section 8A details using the [Get Section 8A details](/api-reference/gst/compliance/endpoints/taxpayer/gstr-9/section_8a_details) endpoint and compare with claimed ITC to identify mismatches before filing.
  </Accordion>
  <Accordion title="What do I do if filing is submitted but not showing as filed?">
    GSTR-9 filing may take time to reflect on the GST portal due to GSTN processing delays. Poll the [Get GST return status](/api-reference/gst/compliance/endpoints/taxpayer/common/gst_return_status) endpoint periodically until the status confirms filing completion. If the status remains pending beyond expected timeframes, check for GSTN errors in the response and consult the [error handling guide](/guides/developer-resources/errors).
  </Accordion>
  <Accordion title="How does EVC OTP filing work for GSTR-9?">
    EVC (Electronic Verification Code) OTP filing requires generating an OTP sent to the registered mobile number or email of the authorized signatory. Call the [Generate EVC OTP](/api-reference/gst/compliance/endpoints/taxpayer/authentication/generate_evc_otp) endpoint, then pass the OTP to the [File GSTR-9](/api-reference/gst/compliance/endpoints/taxpayer/gstr-9/file) endpoint to submit the return. EVC is one of the accepted signing methods for GSTR-9 on the GST portal.
  </Accordion>
  <Accordion title="What validations should I run before saving or proceeding?">
    GSTR-9 validations should confirm that all tables are correctly populated and HSN codes match the GST tariff using the [Get HSN](/api-reference/gst/compliance/endpoints/taxpayer/gstr-1/documents/get_hsn) utility. Ensure auto-calculated values and Section 8A ITC reconcile with internal records. Before proceeding, confirm that no mandatory fields are missing - GSTN will reject the proceed step if validations fail. See the [error handling guide](/guides/developer-resources/errors) for common validation errors.
  </Accordion>
  <Accordion title="How should I handle GSTN errors and retries?">
    GSTN errors may occur due to portal downtime, session expiry, or validation failures. The GSTR-9 API returns standardized error codes - implement retry logic with exponential backoff for transient errors (5xx, timeouts). For validation errors (4xx), parse the error details and correct the request payload. Refer to the [error handling guide](/guides/developer-resources/errors) for error code mappings and recommended retry strategies.
  </Accordion>
</AccordionGroup>
