Save TRACES credentials for enriched APIs, which manage login and sessions for you. Use the deductor's TAN in `tan` for either login.

| Login | Request fields |
| :--- | :--- |
| Administrator | Send the administrator's TRACES password in `password`. Omit `pan`. |
| Sub-user | Send the sub-user's PAN in `pan` and that sub-user's TRACES password in `password`. |

Your workspace can save one credential per TAN. To replace saved credentials, [delete the existing credentials](/api-reference/tds/compliance/traces-credentials/endpoints/delete_credential), then add the new credentials.

To obtain tokens for vanilla APIs, use [Authenticate a TRACES deductor](/api-reference/tds/compliance/traces/endpoints/authenticate).
