The TDS certificate API generates TDS and TCS certificates from TRACES. Use a deductor token or saved TRACES credentials to request certificates, check progress, and download PDF ZIP files.

<div id="choose-a-certificate" />

## Supported certificates

The certificate APIs support these forms under the Income-tax Act, 2025. Form 130 is available only through the enriched APIs.

| Certificate | Earlier name | Use it for | Integration |
|:------------|:-------------|:-----------|:------------|
| [Form 130](/recipes/tds/form-130/generate-form-130-certificates) | Form 16 | Salary TDS, pension, or specified senior citizen interest | Enriched APIs only |
| [Form 131](/recipes/tds/form-131/generate-form-131-certificates) | Form 16A | TDS on income other than salary | Deductor token or enriched APIs |
| Form 133 | Form 27D | Tax Collected at Source, or TCS | Deductor token or enriched APIs |

The Income Tax Department documents these mappings in its [Form 130 FAQs](https://www.incometaxindia.gov.in/documents/d/guest/form-130-faqs), [Form 131 FAQs](https://www.incometaxindia.gov.in/documents/d/guest/form-131-faqs), and [Form 133 FAQs](https://www.incometaxindia.gov.in/documents/d/guest/form-133-faqs).

## Choose your integration

Choose how you authenticate the deductor and check job completion.

| Integration | Before you request certificates | Check completion |
|:------------|:--------------------------------|:-----------------|
| [Deductor token](/recipes/tds/certificates/generate-with-deductor-token) | Authenticate the deductor and send the returned deductor access token. You manage token refresh. | Poll the certificate job status. |
| [Enriched APIs](/api-reference/tds/compliance/certificates/endpoints/submit_job) | Save the TRACES credentials for the TAN and send your Sandbox access token. Sandbox manages the TRACES session. | Poll the status or configure an enriched certificate webhook. |

## How it works

<Steps>
  <Step title="Request certificates">
    Select a supported certificate type in your chosen endpoint. Submit the tax year and quarter in the request body. Include the TAN only for enriched requests.
  </Step>
  <Step title="Check progress">
    Poll the status endpoint with the returned `job_id`. Enriched jobs also support [webhook notifications](/api-reference/tds/compliance/certificates/endpoints/webhook).
  </Step>
  <Step title="Download certificates">
    When the job succeeds, download each ZIP file from `data.certificate_pdf_zip_urls` in the status response.
  </Step>
</Steps>

## Before you start

- A Sandbox API key and access token. See the [Quickstart guide](/guides/get-started/quickstart).
- The TAN and its TRACES password.
- The certificate type, tax year, and quarter for the request.
- A statement that TRACES has processed, with certificates available for download.

For the deductor-token workflow, [authenticate the deductor](/api-reference/tds/compliance/traces/endpoints/authenticate) with your Sandbox access token. Use the returned deductor access token for certificate requests. When that token expires, [refresh the deductor session](/api-reference/tds/compliance/traces/endpoints/refresh) before continuing to poll the same job.

For enriched APIs, [save the TRACES credentials](/api-reference/tds/compliance/traces-credentials/endpoints/save_credential) for the TAN. Certificate requests use your Sandbox access token.

<Note>
Form 130 certificate generation is available after the tax year ends and TRACES processes the corresponding Form 138 statement.
</Note>

## Certificate APIs

### With a deductor token

| API | Use it to |
|:----|:----------|
| [Create certificate job](/api-reference/tds/compliance/certificates/endpoints/submit_with_deductor_token) | Request Form 131 or Form 133 certificate generation. |
| [Get certificate job status](/api-reference/tds/compliance/certificates/endpoints/poll_with_deductor_token) | Check progress and retrieve download URLs. |

### Enriched APIs

| API | Use it to |
|:----|:----------|
| [Create certificate job](/api-reference/tds/compliance/certificates/endpoints/submit_job) | Request certificate generation. |
| [Get certificate job status](/api-reference/tds/compliance/certificates/endpoints/poll_job) | Check progress and retrieve download URLs. |
| [Search certificate jobs](/api-reference/tds/compliance/certificates/endpoints/fetch_job) | Find previously submitted jobs. |
| [Certificate webhook](/api-reference/tds/compliance/certificates/endpoints/webhook) | Receive success or failure notifications. |
