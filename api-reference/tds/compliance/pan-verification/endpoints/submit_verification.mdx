[Authenticate a TRACES deductor](/api-reference/tds/compliance/traces/endpoints/authenticate) and pass the returned `data.access_token` as the value of the `Authorization` header. The token identifies the TAN.

Send the [payee workbook](/api-reference/tds/compliance/pan-verification/vanilla_payee_workbook) directly in the request body. Save the returned `data.token_number` to [retrieve verification status](/api-reference/tds/compliance/pan-verification/endpoints/poll_verification).

For authentication, submission, and result download examples, see [Verify PANs with a deductor token](/recipes/tds/pan-verification/verify-pans-with-deductor-token).
