---

Pass the TRACES `token_number` as a query parameter and `deductor_access_token` in the `Authorization` header. This request has no body.

While the report is unavailable, `data` contains `token_number`, the TRACES `status` array, and `rejection_remarks`. Status values and rejection remarks retain the source text.

When the report is available, `data` contains only `output_json_url`. Download the [PAN verification workbook](/api-reference/tds/compliance/pan-verification/vanilla_pan_verification_workbook) from this signed URL within 24 hours. Generated files are retained for 30 days.

If the deductor access token expires, [refresh the deductor session](/api-reference/tds/compliance/traces/endpoints/refresh), then retry this request with the new access token.
