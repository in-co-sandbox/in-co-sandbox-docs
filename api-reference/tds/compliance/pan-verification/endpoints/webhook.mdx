Webhooks fire when a bulk PAN verification job reaches `succeeded` or `failed`.

The webhook's `data` contains the job object, with the same schema as `data` in the [job status response](/api-reference/tds/compliance/pan-verification/endpoints/poll_job). Read `data.output_json_url` after success, or `data.message` after failure.

Configure the webhook before creating the job. See the [webhooks guide](/guides/developer-resources/webhooks) to set your URL and validate `x-sandbox-signature`.
