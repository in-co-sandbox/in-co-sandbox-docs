## Input columns

The table header is `["sr_no", "pan"]`. Each row contains these values in the same order.

| Column | Type | Description |
|:-------|:-----|:------------|
| `sr_no` | Integer | A positive serial number for the input row. |
| `pan` | String | The PAN text to submit to TRACES. |

Sandbox submits PAN strings unchanged. Repeated exact PAN strings are submitted once.

Send this workbook as the JSON body of [Submit PANs for TRACES verification](/api-reference/tds/compliance/pan-verification/endpoints/submit_verification). The request uses a deductor access token and does not contain a TAN.

The [output workbook](/api-reference/tds/compliance/pan-verification/vanilla_pan_verification_workbook) numbers rows from `1` in report order. Input serial numbers do not identify output rows.
