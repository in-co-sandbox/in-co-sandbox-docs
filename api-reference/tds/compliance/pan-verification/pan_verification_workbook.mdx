## Output columns

The table header is `["sr_no", "pan", "pan_status"]`. Each row contains these values in the same order.

| Column | Type | Description |
|:-------|:-----|:------------|
| `sr_no` | Integer | Serial number from the first input row for this PAN. |
| `pan` | String | The submitted PAN returned in the TRACES report. |
| `pan_status` | String | PAN status text returned by TRACES. |

## PAN verification results

Results include only submitted PANs present in the TRACES report. A missing PAN is omitted from the workbook. For repeated exact PAN strings, the output keeps the first input row's `sr_no`.

Sandbox returns `pan_status` exactly as TRACES supplies it. Treat `Valid` and `Valid and Operative` as distinct values. An `Invalid` row does not make the job fail.

## Download the workbook

When the [job status](/api-reference/tds/compliance/pan-verification/endpoints/poll_job) is `succeeded`, download the workbook from `data.output_json_url`. The signed URL is valid for 24 hours. Generated files are retained for 30 days.

For the complete workflow, see [Verify PANs in bulk](/recipes/tds/pan-verification/verify-pans-in-bulk).
