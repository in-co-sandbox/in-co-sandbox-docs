This endpoint uses your Sandbox access token in the `Authorization` header. See the [Quickstart guide](/guides/get-started/quickstart) for Sandbox authentication.

Pass the returned `data.access_token` as the value of the `Authorization` header for [TDS challans](/recipes/tds/challans/check-tds-challans), [bulk PAN verification](/recipes/tds/pan-verification/verify-pans-with-deductor-token), and [certificate jobs](/recipes/tds/certificates/generate-certificates-with-deductor-token).

When the deductor access token expires, use [Refresh a TRACES deductor session](/api-reference/tds/compliance/traces/endpoints/refresh).
