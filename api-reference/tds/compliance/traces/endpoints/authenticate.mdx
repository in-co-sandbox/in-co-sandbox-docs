---
title: "Authenticate a TRACES deductor"
description: "Authenticate a deductor with a TAN and TRACES password to obtain a deductor access token and refresh token."
keywords:
  - TRACES authentication API
  - deductor access token
  - deductor refresh token
openapi: '/api-reference/tds/compliance/openapi.json POST /tds/traces/deductors/authenticate'
---

This endpoint uses your Sandbox access token in the `Authorization` header. See the [Quickstart guide](/guides/get-started/quickstart) for Sandbox authentication.

Save the returned `data.access_token` and `data.refresh_token`. Use `data.access_token` in the `Authorization` header for requests that require a deductor access token.

When the deductor access token expires, use [Refresh a TRACES deductor session](/api-reference/tds/compliance/traces/endpoints/refresh).
