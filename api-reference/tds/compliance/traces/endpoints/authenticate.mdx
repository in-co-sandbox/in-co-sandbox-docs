title: "Authenticate a TRACES deductor"
description: "Authenticate a deductor with a TAN and TRACES password to obtain access and refresh tokens for TDS challan and bulk PAN verification requests."
keywords:
  - TRACES authentication API

openapi: '/api-reference/tds/compliance/openapi.json POST /tds/traces/deductors/authenticate'
---

This endpoint uses your Sandbox access token in the `Authorization` header. Use the returned `data.access_token` to authorize [TDS challan requests](/recipes/tds/challans/check-tds-challans) and [bulk PAN verification requests](/recipes/tds/pan-verification/verify-pans-with-deductor-token).

When the deductor access token expires, use [Refresh a TRACES deductor session](/api-reference/tds/compliance/traces/endpoints/refresh).
