title: "Refresh a TRACES deductor session"
description: "Refresh a TRACES deductor session to continue TDS challan and bulk PAN verification requests without entering the TRACES password."
keywords:
  - TRACES refresh token

  - TDS challan API
  - TRACES bulk PAN verification API
openapi: '/api-reference/tds/compliance/openapi.json POST /tds/traces/deductors/refresh'
---

This endpoint uses your Sandbox access token in the `Authorization` header. See the [Quickstart guide](/guides/get-started/quickstart) for Sandbox authentication.

Pass the deductor refresh token in the request body, then replace both saved deductor tokens with the returned values.

If the refresh token has expired or is rejected, [authenticate the deductor again](/api-reference/tds/compliance/traces/endpoints/authenticate). See [Check TDS challans](/recipes/tds/challans/check-tds-challans) or [Verify PANs with a deductor token](/recipes/tds/pan-verification/verify-pans-with-deductor-token) for the complete flow.
