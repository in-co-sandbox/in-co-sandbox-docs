---
title: "Refresh a TRACES deductor session"
description: "Use a deductor refresh token to obtain new TRACES deductor access and refresh tokens without entering the TRACES password again."
keywords:
  - TRACES refresh token
  - deductor access token
  - TRACES session refresh API
openapi: '/api-reference/tds/compliance/openapi.json POST /tds/traces/deductors/refresh'
---

Send the `deductor_refresh_token` returned by [Authenticate a TRACES deductor](/api-reference/tds/compliance/traces/endpoints/authenticate) in the `Authorization` header. Include your Sandbox API key in `x-api-key`. This request has no body.

Replace both saved deductor tokens with the returned `data.access_token` and `data.refresh_token`.

If the refresh token has expired or is rejected, [authenticate the deductor again](/api-reference/tds/compliance/traces/endpoints/authenticate).
