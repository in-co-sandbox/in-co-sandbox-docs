<Note>
Before you fetch TDS challan details, [add the TRACES credentials](/api-reference/tds/compliance/traces-credentials/endpoints/save_credential) for the TAN. If the credentials already exist, you do not need to add them again.
</Note>

To find challans by deposit date, use [Search TDS challans](/api-reference/tds/compliance/challans/endpoints/search_challans).

See [Check TDS challans](/recipes/tds/challans/check-tds-challans) for credential setup and cURL examples.
