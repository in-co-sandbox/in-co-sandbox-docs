<Note>
[Authenticate a TRACES deductor](/api-reference/tds/compliance/traces/endpoints/authenticate) and pass the returned `data.access_token` as the value of the `Authorization` header. The token identifies the TAN, so the request body does not contain `tan`.
</Note>

To find challans by deposit date, use [Search TDS challans](/api-reference/tds/compliance/challans/endpoints/search_challans).

See [Check TDS challans](/recipes/tds/challans/check-tds-challans) for authentication, token refresh, and cURL examples.
