description: "Search TDS challans on TRACES by deposit date using a deductor access token. Use page number and page size to retrieve matching records."
keywords:
  - TDS challan

openapi: '/api-reference/tds/compliance/openapi.json POST /tds/traces/deductors/challans/search'
---

<Note>
[Authenticate the deductor](/api-reference/tds/compliance/traces/endpoints/authenticate) and pass the returned `access_token` in the `Authorization` header. The token identifies the TAN, so the request body does not contain `tan`.
</Note>

To look up a challan with its payment details, use [Fetch TDS challan details](/api-reference/tds/compliance/challans/endpoints/fetch_challan).

See [Check TDS challans](/recipes/tds/challans/check-tds-challans) for authentication, token refresh, and cURL examples.
