---

<Note>
Before you search TDS challans, [add the TRACES credentials](/api-reference/tds/compliance/traces-credentials/endpoints/save_credential) for the TAN. If the credentials already exist, you do not need to add them again.
</Note>

To look up a challan with its payment details, use [Fetch TDS challan details](/api-reference/tds/compliance/challans/endpoints/fetch_challan).

See [Check TDS challans](/recipes/tds/challans/check-tds-challans) for credential setup and cURL examples.
