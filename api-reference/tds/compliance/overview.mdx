Sandbox's TDS compliance API provides file validation and electronic filing for Tax Deducted at Source (TDS) and Tax Collected at Source (TCS) returns. Use it to add quarterly return filing to your payroll, accounting, or tax software.

<div id="choose-a-capability" />

## FVU generation and e-filing

FVU generation validates return files using the File Validation Utility (FVU). E-filing submits the validated return.

| Capability | What you provide | What you receive |
|:-----------|:-----------------|:-----------------|
| [FVU generation](/api-reference/tds/compliance/generate-fvu/endpoints/submit_job) | Return text file and supporting files | FVU ZIP on success, or a validation report on validation failure |
| [E-filing](/api-reference/tds/compliance/e-file/endpoints/submit_job) | ZIP containing the FVU file and Form 27A | Filing receipt and links to the filed documents on success |

For related tasks, use the [CSI download APIs](/api-reference/tds/compliance/download-csi/endpoints/generate_otp) to retrieve Challan Status Inquiry files, or the [TDS certificate API](/api-reference/tds/compliance/certificates/overview) to generate certificates after TRACES processes the relevant statement and makes certificates available.

## Supported return forms

FVU generation and e-filing support these return forms:

| Return form | Earlier name | Use it for |
|:------------|:-------------|:-----------|
| Form 138 | Form 24Q | Salary TDS returns |
| Form 140 | Form 26Q | Non-salary TDS returns for payments to residents |
| Form 144 | Form 27Q | TDS returns for payments to non-residents |
| Form 143 | Form 27EQ | TCS returns |

See the Income Tax Department's [transition FAQs](https://www.incometaxindia.gov.in/documents/81799/11848482/Updated-FQAs-on-Interplay%26Transitions.pdf/e10ad2b6-9495-de90-58d3-20606d8954ae) for the statutory form changes. For certificate forms, see the [certificate overview](/api-reference/tds/compliance/certificates/overview#choose-a-certificate).

## Requirements

- A Sandbox API key and access token. Follow the [Quickstart guide](/guides/get-started/quickstart).
- The TAN, return form, tax year, and quarter for the job.
- The input files listed above.

FVU generation supports regular and correction returns. See the [FVU endpoint](/api-reference/tds/compliance/generate-fvu/endpoints/submit_job) for upload requirements.

<div id="how-it-works" />

## Return filing workflow

<Steps>
  <Step title="Create an FVU generation job">
    Create a job, then upload the return text file and supporting files to the returned URLs.
  </Step>
  <Step title="Check the validation result">
    Download the FVU ZIP after validation succeeds. If validation fails, check the report and correct the input files.
  </Step>
  <Step title="Create an e-filing job">
    Create an e-filing job, then upload the ZIP containing the FVU file and Form 27A.
  </Step>
  <Step title="Retrieve the filing result">
    Download the receipt after the job succeeds. If it fails, read the failure message.
  </Step>
</Steps>

Both operations run asynchronously. Creating a job does not complete validation or filing. You can configure [webhooks](/guides/developer-resources/webhooks) before submitting jobs to receive success or failure notifications. See the [job-based API workflow](/guides/developer-resources/job_based_apis#how-it-works) for file-upload instructions.

## Frequently asked questions

<AccordionGroup>
  <Accordion title="Does FVU validation also file the return?">
    No. FVU generation validates your return files. Submit the validated return through the e-filing API.
  </Accordion>
  <Accordion title="Does a successful e-filing job mean certificates are available?">
    TRACES processes the statement after filing. Check the [certificate prerequisites](/api-reference/tds/compliance/certificates/overview#what-you-need) before requesting certificates.
  </Accordion>
  <Accordion title="How do I investigate a failed job?">
    The FVU status response can contain a validation report URL. The e-filing status response includes a failure message. For errors returned by the API request itself, see the [API errors guide](/guides/developer-resources/errors).
  </Accordion>
</AccordionGroup>
