Sandbox's TDS compliance APIs support return validation, e-filing, and certificate generation. Use them to download CSI files, file quarterly TDS and TCS returns, and retrieve certificates in your payroll, accounting, or tax software.

## Generate certificates through TRACES

Choose the certificate workflow that fits your integration:

- [Use a deductor token](/recipes/tds/certificates/generate-with-deductor-token) for Form 131 or Form 133. You authenticate the deductor, refresh tokens, and poll the job status.
- [Use saved TRACES credentials](/api-reference/tds/compliance/certificates/endpoints/submit_job) with the enriched APIs for Form 130, Form 131, or Form 133. Sandbox manages the TRACES session. You can poll the job status or configure an enriched [certificate webhook](/api-reference/tds/compliance/certificates/endpoints/webhook).

Both workflows return a `job_id` to check progress and retrieve the certificate download URLs. See the [certificate overview](/api-reference/tds/compliance/certificates/overview#choose-your-integration) to compare them.

## How it works

Follow these steps to file a return. If you already have the FVU file and Form 27A, start at step 3.

<Steps>
  <Step title="Download the CSI file">
    Download the Challan Status Inquiry file to validate the challans in your return.
  </Step>
  <Step title="Validate the return">
    Upload your return text file and supporting files. The File Validation Utility (FVU) checks them and generates the filing package, or reports errors to fix.
  </Step>
  <Step title="E-file the return">
    Submit the FVU file and Form 27A for e-filing. Check the filing status and download the receipt once the job succeeds.
  </Step>
</Steps>

<Note>
  To generate certificates, wait until TRACES processes the relevant statement and makes the certificates available. Then use the [TDS certificate API](/api-reference/tds/compliance/certificates/overview) to generate and download them.
</Note>

## Supported return forms

FVU generation and e-filing support these return forms:

| Return form | Earlier name | Use it for |
|:------------|:-------------|:-----------|
| Form 138 | Form 24Q | Salary TDS returns |
| Form 140 | Form 26Q | Non-salary TDS returns for payments to residents |
| Form 144 | Form 27Q | TDS returns for payments to non-residents |
| Form 143 | Form 27EQ | TCS returns |

See the Income Tax Department's [transition FAQs](https://www.incometaxindia.gov.in/documents/81799/11848482/Updated-FQAs-on-Interplay%26Transitions.pdf/e10ad2b6-9495-de90-58d3-20606d8954ae) for the statutory form changes. For certificate forms, see the [certificate overview](/api-reference/tds/compliance/certificates/overview#supported-certificates).

## Before you start

Get your API key and access token from the [Quickstart guide](/guides/get-started/quickstart). Prepare the files and details for your workflow:

- [Return validation](/api-reference/tds/compliance/generate-fvu/endpoints/submit_job): A return text file and supporting files.
- [E-filing](/api-reference/tds/compliance/e-file/endpoints/submit_job): An FVU file and Form 27A.
- [Certificates](/api-reference/tds/compliance/certificates/overview#requirements): A deductor token or saved TRACES credentials, and certificates available for the requested period.

FVU generation and e-filing run as background jobs with file uploads. See the [job-based API workflow](/guides/developer-resources/job_based_apis#how-it-works) for uploads and completion checks. Certificate jobs take the period details directly in the request body and require no file upload.

## API reference

### CSI download APIs

| API | Purpose |
|:----|:--------|
| [Generate OTP for CSI download](/api-reference/tds/compliance/download-csi/endpoints/generate_otp) | Send an OTP to request a CSI file. |
| [Verify OTP for CSI download](/api-reference/tds/compliance/download-csi/endpoints/verify_otp) | Verify the OTP to download the CSI file. |

### FVU generation APIs

| API | Use it to |
|:----|:----------|
| [Create FVU generation job](/api-reference/tds/compliance/generate-fvu/endpoints/submit_job) | Start validation and get file upload URLs. |
| [Check FVU generation status](/api-reference/tds/compliance/generate-fvu/endpoints/poll_job) | Check progress and retrieve validation results. |
| [Search FVU generation jobs](/api-reference/tds/compliance/generate-fvu/endpoints/search_job) | Find previously submitted jobs. |
| [FVU generation webhook](/api-reference/tds/compliance/generate-fvu/endpoints/webhook) | Receive completion notifications. |

<div id="e-file-apis" />

### TDS e-filing APIs

| API | Use it to |
|:----|:----------|
| [Create TDS return e-filing job](/api-reference/tds/compliance/e-file/endpoints/submit_job) | Start a filing job and get the file upload URL. |
| [Check TDS return e-filing status](/api-reference/tds/compliance/e-file/endpoints/poll_job) | Check the filing result and download the receipt. |

| [TDS e-filing webhook](/api-reference/tds/compliance/e-file/endpoints/webhook) | Receive completion notifications. |

### TDS certificate APIs

See the [certificate endpoints](/api-reference/tds/compliance/certificates/overview#certificate-endpoints) to create a certificate job and check its status. The enriched certificate APIs also support job searches and webhooks.
