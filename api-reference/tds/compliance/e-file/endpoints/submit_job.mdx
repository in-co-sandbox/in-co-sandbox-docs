---
title: "Create TDS return e-filing job"
description: "E-file a TDS or TCS return using your FVU file and Form 27A."
keywords:
  - create tds return e-filing job
  - TDS e-filing API
openapi: '/api-reference/tds/compliance/openapi.json POST /tds/compliance/e-file'
---

After creating the job, upload a ZIP containing the FVU file and Form 27A to `data.fvu_upload_file_url` using HTTP PUT. Save `data.job_id` to [check the filing result](/api-reference/tds/compliance/e-file/endpoints/poll_job). Creating the job does not file the return.


<Note>
  For HTTP PUT upload instructions, see the [job-based API workflow](/guides/developer-resources/job_based_apis#how-it-works).
</Note>
