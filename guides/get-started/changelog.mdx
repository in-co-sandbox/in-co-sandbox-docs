Our [<u>Changelog</u>](https://developer.sandbox.co.in/changelog) keeps you informed about the latest features, enhancements, bug fixes, and improvements across Sandbox.

### **Subscribe to our Changelog**

Stay up-to-date by subscribing to our Changelog RSS feed to ensure you never miss any important changes or announcements.

RSS Feed URL: `https://developer.sandbox.co.in/changelog.rss`

### **Using Slack**

1. Install the RSS App from the Slack App Directory
2. Use the command `/feed subscribe https://developer.sandbox.co.in/changelog.rss` in any channel where you want to receive updates.

### **Using Microsoft Teams**

1. Install the RSS Connector from Connectors
2. Enter the RSS feed URL and follow the prompts to configure

### **Using Discord**

1. Install an RSS Bot like "Webhook RSS" to your server.
2. Use the bot’s commands to subscribe to the feed using the RSS feed URL.

### **Using an RSS Reader**

1. Select an RSS reader such as Feedly, Inoreader, or Reeder (iOS)
1. Add the RSS Feed using the RSS Feed URL
   - Feedly: Click "Add Content," paste the URL, and click "Follow."
   - Inoreader: Click "Subscribe," paste the URL, and click "Subscribe."
   - Reeder (iOS): Tap "Add," paste the URL, and tap "Subscribe"
