### **Consumption**

Not every API request counts towards the quota. Similarly, not every API request incurs wallet charges. For instance, failed API requests (5xx status code) don't count towards quota consumption nor incur wallet charges. Read below to understand when quota counts and when wallet charges are incurred, based on the different response status codes.

### **Quota Consumption**

Quota is consumed only in 200 (successful) calls.

### **Wallet Charges**

Wallet charges are only applicable on 200 (successful) calls.
