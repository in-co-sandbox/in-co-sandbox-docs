Quota is the number of API calls a customer can make in a given month without incurring additional charges. The quota is as per the plan a customer subscribes to. The quota is always on a monthly basis. 

<Warning>
  **The left-over quota does not carry forward to the next month.**
</Warning>

Quota helps us provision resources for our customers who come in all sizes. Quota also ensures that one customer does not block all available resources and starve other customers of resources.

You can refer to the quota for the standard plans here:

| **Plan**   | **Pricing (Monthly)** | **Quota**          |
| :--------- | :-------------------- | :----------------- |
| Startup    | ₹999                  | 1,000 API Calls    |
| Growth     | ₹9,999                | 30,000 API Calls   |
| Unicorn    | ₹16,999               | 1,00,000 API Calls |
| Enterprise | On Request            | On Request         |
