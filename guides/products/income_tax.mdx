# Income Tax

Sandbox Income Tax APIs help automate tax computation, reporting (ITR generation), and document parsing (Form 16 OCR) for individuals and businesses.

Income tax is a form of direct tax levied on the income generated by persons (Individuals, Companies, etc.). It is collected by the Central Government to fund public projects and initiatives. Income is classified into 5 different sources: Income from Salary, Business & Professional, Capital Gains, House Property, and Income from Other Sources.

In the case of Individuals/ HUF, it is mandatory to file the ITR if their gross income in a year exceeds the basic exemption limit of INR 2.5 lakhs. Whereas for companies, firms, etc. it is compulsory to file the ITR irrespective of their income.

However, the calculation of tax liability can change depending on any new guidelines issued by the government during the budget session or additional notification by the income tax department, thereby, making managing tax computation difficult and prone to error.

Sandbox has built Income tax APIs for businesses to integrate into their existing workflows and automate end-to-end Income tax compliance without stressing about the constantly changing ecosystem.

### Calculator API

The Calculator APIs facilitate calculations, including precise tax liability and advance tax liability computation, depending on various tax regimes. Additionally, businesses can determine profits and losses, along with tax liability for Domestic, Foreign, or Crypto trades, using various input formats such as tradewise, scripwise, or tradebook.

### Report API

The Report API serves two main purposes: first, it aids in preparing Income Tax Returns (ITR) by generating a JSON file suitable for uploading onto the Income Tax portal for tax filing. The second set of APIs assists in producing comprehensive and detailed Tax Profit and Loss (PnL) Reports for domestic securities, foreign securities, or crypto.

### OCR API

The OCR API helps to read and classify certain ITR related documents like Form 16. As it helps to extract relevant details by reading and classifying the document.

## Base URL

All Income Tax APIs are served from the sandbox host. Use the environment host variable when running requests:

- Base URL: `{{sandbox_host}}`

## Authentication

Most endpoints require an authenticated request. Typical headers you will need:

- `Authorization: Bearer <JWT access token>`
- `x-api-key: <your-api-key>`
- Optional: `x-api-version: <version>`

Refer to the Authentication docs for generating tokens and API keys: `/api-reference/authenticate`.

## Implementation notes & best practices

- Prefer the Report API for producing ITR-ready JSON that you will upload to the government portal.
- Use OCR to prefill fields from documents like Form 16 before running Calculator or Report flows.
- For large datasets, implement job-based / async flows (submit job -> poll job status -> download report when ready).
